This guide walks you through step-by-step: installing PostgreSQL,
verifying your setup, using the \texttt{psql} console, loading the
Pagila sample database, and using beginner-friendly GUI clients. Clear
tips and quick solutions are included throughout.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{Before You Start}\label{before-you-start}

\textbf{Key Terms (Quick Reference)} - \textbf{Server} --- the
PostgreSQL database engine running on your PC - \textbf{Client} ---
tools you use to communicate with the server (e.g., \texttt{psql},
pgAdmin, DBeaver) - \textbf{Database} --- a container for tables, views,
etc. (one server can host multiple databases) - \textbf{Role/User} ---
an account that logs in and has permissions

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{Installing PostgreSQL
(Windows)}\label{installing-postgresql-windows}

\subsubsection{Download PostgreSQL}\label{download-postgresql}

\textbf{Official Link:}
\url{https://www.postgresql.org/download/windows/}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Open the \textbf{official PostgreSQL for Windows} page and choose
  \textbf{Interactive installer by EDB}
\item
  Download the latest stable version for \textbf{Windows x86‑64}
\item
  Run the installer (\texttt{.exe}) and keep the default components:
  \textbf{Server}, \textbf{pgAdmin}, \textbf{Command Line Tools}
\item
  When prompted, \textbf{set a password for the superuser
  \texttt{postgres}} and keep it safe
\item
  Keep the \textbf{Port} at \texttt{5432} and accept the default
  \textbf{Locale}
\item
  Complete the installation wizard
\end{enumerate}

\begin{quote}
\textbf{Installed Components} - \textbf{PostgreSQL Server} --- the
engine that stores your data\\
- \textbf{\texttt{psql}} --- the command-line SQL shell\\
- \textbf{pgAdmin} --- the official graphical management tool
\end{quote}

you see \texttt{postgres=\#}, you're good.

\subsubsection{\texorpdfstring{What is \texttt{psql}? (Gentle
Introduction)}{What is psql? (Gentle Introduction)}}\label{what-is-psql-gentle-introduction}

\begin{itemize}
\tightlist
\item
  \textbf{\texttt{psql}} is a text console for communicating with
  PostgreSQL. You type a command, press \textbf{Enter}, and the server
  responds
\item
  \textbf{Why learn it?} It's fast, matches official documentation, and
  helps you troubleshoot even when a GUI can't connect
\item
  \textbf{What you'll see:} a prompt like \texttt{postgres=\#} (or your
  database name). End SQL statements with a \textbf{semicolon}
  (\texttt{;}). If you forget it, \texttt{psql} will wait for more input
\item
  \textbf{Two types of commands:}

  \begin{itemize}
  \tightlist
  \item
    \textbf{SQL} (ends with \texttt{;}) --- e.g.,
    \texttt{SELECT\ version();}
  \item
    \textbf{Meta-commands} (start with backslash) --- e.g.,
    \texttt{\textbackslash{}dt} (list tables),
    \texttt{\textbackslash{}d\ film} (describe a table). These are
    \texttt{psql} features, not SQL
  \end{itemize}
\item
  \textbf{Mini Demo:}
\end{itemize}

\begin{Shaded}
\begin{Highlighting}[]
\KeywordTok{SELECT} \DecValTok{1}\NormalTok{;}
\KeywordTok{CREATE} \KeywordTok{DATABASE}\NormalTok{ testdb;}
\NormalTok{\textbackslash{}c testdb}

\KeywordTok{DROP} \KeywordTok{TABLE}\NormalTok{ t;}

\end{Shaded}

\begin{itemize}
\tightlist
\item
  \textbf{Common Beginner Mistakes:} missing semicolon; connecting to
  wrong database; doing everything as superuser \texttt{postgres}
  (create a normal user for daily work)
\end{itemize}

\texttt{psql} is the \textbf{librarian's desk}: you ask for things (SQL)
and get answers. GUIs add maps and buttons, but the desk still works.
\end{quote}

\subsubsection{Common GUI Pitfalls}\label{common-gui-pitfalls}

\begin{itemize}
\tightlist
\item
  \textbf{Service not started:} Launch \textbf{Services} →
  \emph{PostgreSQL } → \textbf{Start/Restart}
\item

  \textbf{5432}. If \emph{localhost} fails, try \textbf{127.0.0.1}
\item
  \textbf{Wrong credentials/database:} Ensure the \textbf{user} and
  \textbf{database} exist; test with \texttt{psql} first
\item
  \textbf{Saved/stale password:} Update saved password in your GUI
\item
  \textbf{SSL prompts (local):} For local work, SSL is usually
  unnecessary --- set mode to \textbf{Prefer} (or \textbf{Disable} if
  allowed) unless your setup requires SSL
\end{itemize}

\subsection{Troubleshooting (Quick
Reference)}\label{troubleshooting-quick-reference}

\begin{verbatim}
"psql is not recognized ..."
  - Use Start → SQL Shell (psql) (no PATH needed), or add
    C:\Program Files\PostgreSQL\<version>\bin to PATH; reopen terminal.

"password authentication failed for user 'postgres'"
  - Retype carefully (case-sensitive). If you can connect via pgAdmin, 
    change password there. Completely stuck on fresh install? Reinstall 
    may be fastest.

"could not connect to server" / timeouts
  - Ensure PostgreSQL service is running (Services). Check host localhost 
    and port 5432.

"Port already in use"
  - Another app is using 5432. Stop it, or install PostgreSQL on a different 
    port (e.g., 5433) and use that port in clients.

"relation does not exist"
  - Check you're connected to the right database (\c dbname)
  - Verify table name spelling (case-sensitive if quoted)
  - Use \dt to list available tables

"syntax error at or near..."
  - Check for missing semicolons
  - Verify SQL keyword spelling
  - Check for unmatched quotes or parentheses

"OWNER TO student" appears in a Pagila schema file
  - That is a course-modified file, not the official Pagila file.
  - Download the official `pagila-schema.sql` again instead of editing it.
\end{verbatim}

\subsection{Common Student Mistakes}\label{common-student-mistakes}

\begin{itemize}
\tightlist
\item
  ❌ \textbf{Forgetting semicolons} in SQL statements
\item
  ❌ \textbf{Using Windows backslashes} (\texttt{\textbackslash{}}) in
  file paths in \texttt{psql} (use \texttt{/})
\item
  ❌ \textbf{Staying connected to wrong database} (use
  \texttt{\textbackslash{}c} to switch)
\item
  ❌ \textbf{Running DDL commands without thinking} (DROP, DELETE
  without WHERE)
\item
  ❌ \textbf{Mixing SQL and meta-commands} (meta-commands don't need
  \texttt{;})
\item
  ❌ \textbf{Not checking which database you're in} before creating
  tables
\item
  ❌ \textbf{Forgetting quotes} around string values in WHERE clauses
\item
  ❌ \textbf{Case sensitivity issues} with table/column names when using
  quotes
\end{itemize}
