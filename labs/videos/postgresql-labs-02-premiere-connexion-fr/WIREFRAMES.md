# Wireframes - épisode 02/08

Les sept wireframes sont les compositions `compositions/frames/01-07-*.html`. Ils utilisent une hiérarchie simple, des surfaces inventées et une bande basse de 200 px réservée aux sous-titres.

| Frame | Structure confirmée | Focal |
|---|---|---|
| 01 | Titre à gauche, checklist des résultats à droite | Ouvrir, connecter, vérifier, quitter |
| 02 | Menu Démarrer stylisé + zoom sur l'entrée | SQL Shell (psql) |
| 03 | Terminal + quatre prompts en pile | Valeurs par défaut et mot de passe masqué |
| 04 | Terminal en état connecté + panneau d'interprétation | `postgres=#` |
| 05 | Terminal de commandes + reçu de vérification | `SELECT version();`, `\conninfo`, `\l` |
| 06 | Terminal de sortie + panneau dépannage | `\q` et erreurs fréquentes |
| 07 | Carte de confirmation + suite du parcours | Connexion locale validée |
