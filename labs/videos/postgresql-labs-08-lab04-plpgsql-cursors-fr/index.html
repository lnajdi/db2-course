Trois formes

Du plus simple au plus manuel

souvent suffisant

FOR rec IN SELECT

La requete est directement dans la boucle. PostgreSQL gere l'ouverture et la fermeture.

FOR rec IN SELECT ... LOOP
reutilisable

CURSOR FOR

Le curseur est nomme. Il peut devenir plus clair quand la requete est reutilisee ou parametree.

my_cur CURSOR FOR SELECT ...
apprentissage

OPEN / FETCH / CLOSE

Cycle complet, utile pour comprendre. Attention a toujours sortir de la boucle.

FETCH cur INTO rec;
